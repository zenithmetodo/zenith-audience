# El motor de decisión por CRUCES de este plugin

Conocimiento **propio y autocontenido**: si te descargas solo este plugin, tienes
el motor de cruces entero aquí dentro — no necesitas ningún otro plugin.

La skill `cruce` de este plugin (el orquestador) usa este conocimiento inline para
diagnosticar el público (Temperatura × Consciencia × Sofisticación + modificadores),
resolver conflictos, chequear el tráfico frío y decidir qué comunicar, antes de que
las skills de copy de este plugin escriban nada.

**Entradas recomendadas:** `16-logica-del-operador.md` (cómo pensar) · `00-matriz-maestra.md`
(el sistema) · `17-trafico-frio-blueprint.md` (tráfico frío) · `svg/` (los diagramas) ·
`ficha-cruce.html` (la plantilla de la Ficha en HTML, print-to-PDF).

*Doctrina destilada del Método Zenith · v1.3.0. Actualizado el 2026-07-23.*

> **Nota:** el conocimiento aquí describe también el motor standalone con sus sub-agentes (g1-g4, d1-d4, auditor-coherencia, cruce-master). EN ESTE PLUGIN NO HAY sub-agentes: el orquestador es la skill `cruce` INLINE. Donde el conocimiento nombre un sub-agente, entiéndelo como el PASO correspondiente de la skill `cruce`. No hay nada que lanzar ni ningún otro plugin al que ir.
